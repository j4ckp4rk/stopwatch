# Stopwatch

브라우저에서 바로 여는 HTML 스탑워치 두 개예요. 설치나 빌드 없이 파일을 더블클릭하면 돼요.

| 파일 | 설명 |
|---|---|
| `stopwatch.html` | 기본 스탑워치. 시작/정지, 랩, 초기화 |
| `stopwatch_f1.html` | F1 출발 그리드 컨셉. 정지 버튼이 도망가는 장난 UI |

## stopwatch_f1.html

- **출발:** F1 신호등(5열 × 4등)이 1초 간격으로 켜지고, 0.2~3초 랜덤 대기 후 한꺼번에 꺼지면 출발해요.
- **정지 버튼:** 처음엔 LAP 아래에서 평범해 보이지만, 처음 누르면 피트 레인으로 도망가요. 마우스를 피하고, 눌러도 헛탕이 나고, 시간이 갈수록 작아져요. 10번 도망가면 지쳐서 잡을 수 있어요.
- **랩:** 누적(SPLIT)과 구간(LAP)을 함께 보여 주고, 최고(★)·최저(▼)와 평균을 표시해요. 정지하면 마지막 구간도 자동으로 기록돼요.
- **기록 복사**, **새로고침 후 복구**(달리는 중이어도 시간이 이어져요)를 지원해요.
- **옵션:** 신호등 연출 건너뛰기, 정지 버튼 장난 끄기(휴대폰 실사용용).

### 단축키

| 키 | 동작 |
|---|---|
| `Space` | 출발 / 정지 (정지 버튼 장난과 상관없이 항상 동작) |
| `L` | 랩 |
| `Esc` | 신호등 대기 중 출발 취소 |

## 참고

- 시간은 1/100초 단위로 표시하고, 소수 둘째 자리 아래는 내림해요.
- 새로고침 복구와 설정 저장은 브라우저 `localStorage`를 써요. 파일을 직접 여는 방식(`file://`)에서는 브라우저에 따라 저장이 막힐 수 있어요.
